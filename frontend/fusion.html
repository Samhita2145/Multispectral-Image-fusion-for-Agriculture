How it works

The system estimates a Pseudo-NIR band from the RGB image, then combines it with the visible spectrum using NDVI (Normalized Difference Vegetation Index) alongside feature-level fusion. This enhances chlorophyll-related contrast so disease-affected regions — often invisible in plain RGB — become distinguishable before classification.
